# Within Reach : Community Resource Access

A rough responsive HTML/CSS/JavaScript prototype for a Missoula community resource directory.

## Pages
- `index.html` – Home, categories, and How It Works
- `find-help.html` – Anonymous intake form, starter recommendations, searchable resource directory
- `categories.html` – Browse needs
- `resource.html` – Reusable resource detail page template
- `about.html` – About, volunteer/donate links, contact form, privacy note
- `ComponentLibrary/components.html` – Class assignment component library with contents section

## Run locally
Open `index.html` in a browser. No build tools are required.

## GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. In Settings → Pages, deploy from `main` and `/(root)`.

## Important prototype notes
- Intake form is anonymous and runs only in the visitor's browser. It does not save or send responses.
- Contact form is a visual prototype and is not connected to an inbox.
- Resource hours, phone numbers, eligibility, and dates need to be verified with each organization before publishing. The pages intentionally say to confirm current details instead of inventing them.
- Recommendation logic is a starter rule-based filter, not an AI algorithm.
- Replace placeholder blocks with approved images/icons. Keep image credits directly below images.
